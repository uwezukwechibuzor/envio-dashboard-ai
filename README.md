# Envio Dashboard AI

Type a request in plain English — _"Generate me a Uniswap V3 dashboard on Arbitrum: fees, volume and transactions for the last 90 days"_ — and get a live, shareable analytics dashboard built on [Envio](https://envio.dev)'s HyperSync and HyperIndex data. Any protocol or contract, at Envio speed, with an MCP server so AI agents can query the same data directly.
